# デフォルトモデルに Sonnet を使用する

## Status

Accepted

## Context

Opus 5 は、1 問ずつ回答を待つ対話の最中に、ユーザーの回答を自分で書いて対話を進める。  
捏造した回答をその後の前提として扱うため、合意した内容が壊れる。

4 つのセッションログを解析した。

| モデル   | 条件                       | 再現   |
| -------- | -------------------------- | ------ |
| Opus 5   | sync-stepwise スキル       | した   |
| Opus 5   | grill-me スキル            | した   |
| Opus 5   | スキルなし、CLAUDE.md なし | した   |
| Sonnet 5 | sync-stepwise スキル       | しない |

Opus 5 は捏造した回答に続けて、ツール呼び出しの内部記法まで出力した。  
応答を終える箇所で停止せず、会話の続きを生成していると思われる。

スキルの記述、CLAUDE.md、コンテキスト長は、いずれも再現条件から外れた。

## Decision

Claude Code のデフォルトモデルに Sonnet を使用する。  
モデルの能力を要する作業では、その都度 Opus に切り替える。

## Consequences

- 対話スキルで合意内容が汚染されなくなる
- 実装やレビューなど、モデルの能力を要する作業で品質が下がる
- 利用コストが下がる
