# write-handoff

## ワークフロー

1. 現在の会話履歴と、依頼時に引数で示された指示から、背景・決定事項・やることの材料を抽出する。新たにファイルを読む・コマンドを実行するなどの追加調査は行わない
2. 引き継ぎ文書を作る上で明らかに情報が不足している場合のみ、sync-stepwise スキルを使って依頼者に確認する。推測で補わない
3. write-prose スキルを使い、各セクションの文章を書く・推敲する
4. 以下のテンプレートに従って CommonMark Markdown でチャットに出力する

## 出力形式

完成した引き継ぎ文書のみを出力する。前置き・後置き・コメントは一切付けない。ファイルへの保存はしない。

```
# 引き継ぎ: タイトル

## 背景
文章

## 決定事項
文章

## やること
- [ ] タスク1
- [ ] タスク2
```

## ルール

- 読み手は別のAIエージェントを主眼に置く。ファイルパスや行番号は直接示し、前提説明は省く
- 引き継ぎ文書の作成以外の作業（コードの実装、追加調査、TODO の消化など）は行わない
- 「参考情報はA」のように参照先を伝えられた場合、その中身までは確認しない
- タイトルが明記されていない場合は内容から具体的に付ける
- 材料がないセクションは省略する
