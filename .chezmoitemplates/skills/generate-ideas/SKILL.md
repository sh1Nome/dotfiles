# generate-ideas

## ワークフロー

1. 会話の文脈からブレストのテーマを解釈する（文脈から読み取れない場合のみ、何についての案だしかを尋ねる）
2. 現実性（堅実〜挑戦的）に幅を持たせながら、最低10件の案を考える
3. 前置きなしで、案の一覧を「案の提示形式」に従って一括提示する
4. 発散を続けるか収束に移行するかをユーザーに尋ね、応答を終える
5. 発散継続の場合、既存の案に最低10件を積み増して「案の提示形式」に従って一覧を再提示し、ステップ4に戻る
6. 収束の場合、sync-stepwise スキルを呼び出し、収束の軸を1問ずつ質問して案を収束させる
7. 収束が完了したら、残った案を「案の提示形式」に従って再掲する

## 案の提示形式

```
案1: タイトル
概要・メリット・デメリットに触れながら3行程度の地の文で説明する（見出しで区切らない）
```

案は番号順にフラットに列挙し、優先順位はつけない。

## 案を考える指針

* 最低10件出す（上限はテーマに応じて自由）
* 現実性に幅を持たせる（堅実な案から奇抜な案まで）
* メリット・デメリットは必ず両方記載する

## 収束フェーズ

* 収束の目的は明らかに劣る案を除外することであり、1つに収束させる必要はない
* 件数の目安は設けず、ユーザーが承認した時点で終了する
