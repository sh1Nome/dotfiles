# create-short-video

指定区間を編集し、以下の仕様でMP4を書き出す。依頼者が仕様の変更を指定した場合は、その指定を優先する。

## 入力

会話から次の5項目を読み取る。開始・終了を文脈で指定した場合は、まず元動画から該当する場面を探す。不足する項目や、確認しても曖昧な指定だけを質問し、タイトルや時刻を推測しない。

```text
元動画：ファイルのパス
開始：HH:MM:SS、秒数、または「Aが起こったとき」などの場面
終了：HH:MM:SS、秒数、または「Bと画面に表示したとき」などの場面
ゲーム名：
タイトル：
```

開始と終了は別々の形式で指定してよい。時刻は元動画上の時刻として扱う。文脈で指定した場合は、場面を確認してから時刻に置き換える。いずれも `0 ≤ 開始 < 終了 ≤ 元動画の長さ` を確認する。

## 準備

1. FFmpeg・ffprobe と Noto Sans JP の太字を利用できるか確認する。利用できないものがあれば伝える。別のフォントを使う場合も依頼者に伝える。
2. ffprobe などで元動画の長さ、表示上の縦横比、フレームレート、音声トラックの構成を調べる。サンプルアスペクト比と回転情報も考慮する。
3. 映像と、可能なら音声を確認する。文脈で指定した場合は、元動画の再生や画像の抽出で候補を探し、その前後を詳しく確認して開始・終了の時刻を特定する。画面の文字は実際の表示を確かめる。

   候補が複数ある場合や特定できない場合は、候補の時刻や確認できた内容を示し、不足する手掛かりを依頼者に尋ねる。時刻を推測して編集を進めない。

   音声を確認できなければ発言内容を推測せず、指定済みの時刻や映像から特定した時刻に沿って編集する。映像だけでは場面を特定できず、音声も確認できない場合は、そのことを伝えて手掛かりを尋ねる。外部の音声認識モデルは取得しない。

## 出力仕様

| 項目 | 仕様 |
|------|------|
| コンテナ・サイズ | MP4、縦動画、幅1080×高さ1920 px |
| 映像 | スマホで再生しやすい H.264、yuv420p |
| フレームレート | 元動画に合わせる。固定フレームレートは 30000/1001 などの値を保ち、可変フレームレートはフレームの時間間隔を保つ |
| 音声 | AAC、音声トラック1本 |
| セリフ字幕 | 追加しない |

映像と音声を同じ区間で切り出し、出力の先頭時刻を揃える。指定の色はすべて不透明で使う。

## 映像・背景・枠

- 背景は暗い紺色 `#0B1622` の単色にする。グラデーションや模様は付けない。
- 映像の縦横比を保ち、引き伸ばさない。スマホで見やすいように中央を拡大し、左右は各15％程度まで切り取ってよい。
- 映像の表示領域は枠込みで幅1080 px以内に収める。16:9の元動画では枠込みで幅1080×高さ864 px程度を目安にする。この目安に近づけるときも、拡大と中央の切り取りで調整する。
- 重要な被写体やゲームの表示が欠ける場合は、切り取り量を減らす。左右各15％程度を超えて切り取ったり、縦横を別々の倍率で拡大したりして目安の寸法に合わせない。
- 映像の四辺の外側に、青灰色 `#4A6070`、太さ3 pxの実線の枠を付ける。最大幅の場合は内側の映像を幅1074 px以内にし、左右の枠も画面内に収める。
- 枠に角丸・発光・影は付けない。

## ゲーム名・タイトル

- Noto Sans JP の太字を使う。
- 映像の上側に、上から「ゲーム名」「短い横線」「タイトル」の順に配置する。すべて画面の中央に揃え、映像や枠と重ねない。
- ゲーム名は灰色がかった白色 `#B8C4D2` にし、文字サイズはタイトルの半分程度にする。
- 横線は水色 `#76D8F0` にする。
- タイトルは黄色 `#FFE082` にし、スマホで読みやすい大きな文字にする。長い場合は文言を変えず、意味の切れ目で改行し、文字や行が画面からはみ出さないようにする。

## 音声

- ゲーム音と会話を別トラックで収録している場合は、それぞれの内容を確認して音量を調整し、会話を聞き取りやすくしてから1本にミックスする。
- 同じ音声を含むトラックを重ねない。全体ミックスと個別トラックが共存する場合は、全体ミックスだけを使うか、必要な個別トラックだけを使う。区別できなければ使用するトラックを確認する。
- ゲーム音と会話がすでに1本のトラックに混ざっている場合は、そのトラックを使って音量やダイナミクスを調整する。分離して調整できたとは報告しない。
- 音声を聴けない場合も、音量解析で確認できる範囲は調整する。会話の聞き取りやすさは未確認として伝える。
- 音声がない場合はその事実を伝え、無音の音声トラックを作って要件を満たしたことにしない。

## 保存・確認・報告

1. 元動画を残し、完成したMP4を `shorts/` に保存する。出力先の指定がなければ、元動画と同じディレクトリに `shorts/` を作る。ファイル名は入力の「タイトル」と「ゲーム名」を ` - ` でつなぎ、`<タイトル> - <ゲーム名>.mp4` とする。ファイル名に使えない文字や改行は `_` に置き換える。同名の完成ファイルがある場合は上書きせず、タイトルの末尾に連番を付ける。
2. 書き出した動画の先頭・中間・末尾から画像を取り出し、映像の縦横比と切り取り、背景、文字の欠けや重なり、枠の四辺を確認する。
3. ffprobe などで解像度、フレームレート、長さ、音声トラック数を確認する。長さは「終了−開始」と比較し、差が出た場合はフレームや音声の区切りによるものか調べる。可変フレームレートは平均値だけで判断せず、フレームの時間間隔も確認する。
4. 全区間をデコードして映像・音声のエラーを確認し、可能なら試聴して音量と音ずれも確認する。不具合を見つけたら修正して再確認する。
5. 完成ファイルへのリンクと元動画上の開始・終了時刻を報告する。文脈で指定した場合は、対応する出来事や画面の表示も添える。確認できなかった項目や残る問題があれば明記し、未確認の内容を確認済みと報告しない。
