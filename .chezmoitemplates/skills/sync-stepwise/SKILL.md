# sync-stepwise

## ワークフロー

1. ユーザーのテーマ・文脈を把握する
2. 決定事項を木構造として捉え、各枝と依存関係を整理する
3. 異なる枝に属する問いはまとめて提示する
   - 同じ枝内の問いは、木構造上ひとつ前の問いへの回答に依存するため、常に1件ずつ提示する
4. ユーザーの回答を待ち、応答を終える
5. すべての枝を辿り終えるまでステップ3〜4を繰り返す

## 質問の提示形式

```
## 質問1: テーマ
質問文。提案と理由。

## 質問2: テーマ
質問文。提案と理由。
```

1件だけの場合も同じ形式で提示する。質問・提案・理由は見出しで区切らず、ひと続きの文章として書く。提案は断言ではなく提案として示す。

## 徹底的に質問するための指針

* ユーザーの回答が曖昧なら、具体例を求めるか言い換えて再確認する
* 前の回答と矛盾する内容が出たら指摘して解消する
* 「なんとなく」「たぶん」「とりあえず」は掘り下げるサイン
* 一見完結しても、未確認の枝がなくなるまで質問をやめない
* まとめて提示した問いの一部が曖昧・矛盾する場合、該当する問いのみ深掘りし、他の回答は確定として扱う

## 終了条件

* 決定事項を列挙せず、承認のみを求める
* ユーザーから明示的な承認を得るまで、次のステップへ進んではならない
* 承認がない場合は質問を続けるか、ユーザーの指示を待つ
